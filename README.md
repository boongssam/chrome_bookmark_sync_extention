# 🔄 붕쌤 북마크 동기화 (v0.2)

서로 다른 구글 계정으로 로그인한 크롬 프로필끼리, **북마크바 전체**를 똑같이 맞춰 주는 확장 프로그램입니다. (기타 북마크·모바일 북마크는 동기화하지 않습니다)

```
[크롬 프로필 A: 개인 계정]  ─┐
                              ├─▶  구글 앱스 스크립트 (주 계정 하나에만 설치)
[크롬 프로필 B: 학교 계정]  ─┘        └─ 구글 드라이브의 bookmark-sync-data.json
```

크롬에 로그인한 계정이 달라도 상관없습니다. 두 프로필 모두 **같은 웹 앱 주소 + 같은 토큰**으로 서버에 접속합니다.

> 시작 전에 각 프로필에서 북마크를 백업해 두세요. (북마크 관리자 `chrome://bookmarks` → 오른쪽 위 ⋮ → **북마크 내보내기**)

---

## 1단계. 서버 만들기 (한 번만, 계정 하나에서)

1. https://script.google.com 접속 → **새 프로젝트**
2. 기본 코드를 모두 지우고 `server/Code.gs` 내용을 붙여넣은 뒤 저장
3. 위쪽 함수 선택 칸에서 **setup** 을 고르고 **실행** → 권한 승인
   (“확인되지 않은 앱” 화면이 나오면 **고급 → (프로젝트 이름)으로 이동**)
4. 아래 **실행 로그**에 나온 `토큰: xxxxxxxx-...` 값을 복사해 둡니다
5. 오른쪽 위 **배포 → 새 배포** → 유형 ⚙ **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. **배포** → 나오는 **웹 앱 URL**(`.../exec`로 끝남)을 복사해 둡니다

> “모든 사용자”여도 토큰을 모르면 아무것도 읽거나 쓸 수 없습니다.
> 학교(교육청) 구글 계정은 관리자 정책으로 이 설정이 막혀 있을 수 있으니, **서버는 개인 Gmail 계정에** 만드는 것을 권장합니다.

## 2단계. 확장 프로그램 설치 (프로필마다)

1. 받은 zip 파일의 압축을 풉니다
2. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → `extension` 폴더 선택
4. 다른 계정 프로필로 전환해서 2~3을 똑같이 반복

## 3단계. 연결하기 (프로필마다)

1. 퍼즐 아이콘 🧩 → **붕쌤 북마크 동기화** (📌 고정하면 편합니다)
2. **웹 앱 URL**과 **토큰** 붙여넣기 → **저장**
3. 상태 칸에 "마지막 동기화"가 나오면 연결 완료입니다. 처음 연결할 때 두 프로필의 북마크바가 **합집합**으로 합쳐집니다

---

## 언제 동기화되나요?

- 북마크를 추가·삭제·수정·이동하면 **3초 뒤** 자동
- 그 외에 **5분마다**, 크롬을 켤 때 자동
- 팝업의 **지금 동기화** 버튼으로 즉시

## 동작 규칙

| 상황 | 결과 |
|---|---|
| 한쪽에서 추가 | 다른 쪽에도 추가 |
| 한쪽에서 삭제 | 다른 쪽에서도 삭제 |
| 제목·순서 변경 | 마지막에 바꾼 쪽 기준으로 반영 |
| 두 컴퓨터에서 동시에 저장 | 서버가 하나를 거절 → 자동으로 다시 합쳐서 저장 |
| 처음 연결 | 양쪽 북마크를 **합집합**으로 합침 (아무것도 지우지 않음) |
| 한 컴퓨터에서 절반 넘게 한꺼번에 삭제 (10개 이상일 때) | **동기화를 멈추고** 아이콘에 빨간 ! 표시 |

## v0.1에서 업데이트하는 경우

1. 새 파일로 `extension` 폴더 내용을 바꿔 넣기
2. 두 프로필 모두 `chrome://extensions` → **붕쌤 북마크 동기화** 카드의 **↻ 새로고침**
3. 🔄 동기화 폴더 안의 북마크는 북마크바로 자동으로 꺼내지고, 빈 폴더는 지워집니다

## 알아 두실 점 (현재 버전의 한계)

- 같은 폴더 안에 **같은 주소의 북마크가 두 개**면 하나로 합쳐집니다.
- **폴더 이름을 바꾸면** “옛 폴더 삭제 + 새 폴더 추가”로 처리됩니다(내용은 유지).
- 북마크 **주소(URL)를 수정**하면 “삭제 + 추가”로 처리됩니다.
- 크롬 웹 스토어에 올린 것이 아니라서, 크롬을 켤 때 개발자 모드 확장 프로그램 알림이 뜰 수 있습니다.

## 문제가 생겼을 때 (팝업 → “문제가 생겼을 때”)

- **강제 동기화**: 대량 삭제 안전장치를 건너뛰고 한 번 동기화합니다. 의도적으로 많이 지웠을 때만 쓰세요.
- **기록 초기화**: 다음 동기화를 처음 연결할 때처럼 “합집합”으로 진행합니다. 뭔가 꼬였을 때 안전하게 다시 맞추는 방법입니다.
- 서버 데이터는 구글 드라이브의 `bookmark-sync-data.json`에 있고, 드라이브의 **버전 관리**로 예전 상태를 볼 수 있습니다.

## 파일 구성

```
bookmark-sync/
├─ README.md
├─ server/Code.gs          구글 앱스 스크립트 (서버)
└─ extension/
   ├─ manifest.json        확장 프로그램 설정
   ├─ background.js        자동 동기화 (이벤트·5분 주기·충돌 재시도·안전장치·v0.1 이전)
   ├─ sync-core.js         3자 병합 로직
   ├─ popup.html / .js     설정·상태 화면
```
